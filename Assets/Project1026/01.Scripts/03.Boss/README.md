- 제공된 7종 동작, 52장 스프라이트를 `08.Resources/03.Boss/GwaegangWhiteTiger`에 압축 해제하고 프리팹에 연결했습니다. 원본 기획서와 ZIP은 보존했습니다.
- HP 800 / 공격력 75 / 방어력 20 / 이동속도 6. 할퀴기 2초, 발 구르기 최초 10초·쿨타임 10초, 도약 최초 6초·쿨타임 6초입니다.
- 발 구르기 > 할퀴기/추적 순으로 거리에 맞게 선택합니다. 공격과 후딜 중에는 다른 행동을 시작하지 않습니다.
- 피해는 플레이어에게만 적용하며 공격당 한 번 판정합니다. 발 구르기 원피해 113, 도약 원피해 150을 기존 플레이어 방어력 계산으로 전달합니다.
- 할퀴기는 시전 시 방향을 고정하고 도약은 준비 시작 시 착지점을 고정합니다. 증강 선택과 일시정지는 보스의 시간도 정지합니다.
- 사망 애니메이션 완료 후 기존 스테이지 보상을 한 번 지급하고 보상 패널을 표시합니다. 버튼으로 마을에 복귀합니다.

## 확인 방법

Unity 메뉴 `Project1026 > Boss > Verify White Tiger`에서 실제 프리팹·피해 레지스트리·전투 종료 흐름에 대한 26개 검증을 실행합니다. 플레이 모드 밖에서 실행하며 저장 데이터는 변경하지 않습니다.

`Rebuild White Tiger Assets`는 스프라이트 임포트와 프리팹 및 StageData01 연결을 다시 생성합니다. 프리팹을 수동 조정했다면 재생성 전에 변경 내용을 보관하세요.

기획서에 명시되지 않은 할퀴기/사망 재생 시간은 각각 0.8초, 스프라이트 PPU는 64로 정했습니다. 보스 프리팹 Inspector에서 능력치와 재생 시간을 조정할 수 있습니다. 별도 보스 스테이지 데이터가 없어 기존 1스테이지 마지막에 연결했습니다.
